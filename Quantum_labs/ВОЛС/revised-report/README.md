Исправленный отчёт с пересчётом задержки и ослабления. [PDF отчёта](report.pdf) · [Исходник LaTeX](main.tex)

## Источники

- Пометки к практической части и заключению находятся на с. 27–29, 31 и 34. [Исходный отчёт с пометками](../ВОЛС_Куприн_Кузькин%281%29%281%29.pdf)
- Теория, титульные сведения и схема взяты из полного архива, восстановленного из коммита `903039d`. В текущем каталоге исходный ZIP содержит два байта. [Архив в истории Git](https://github.com/NickKuprin-cpu/Uni_stuff/blob/903039d039b9b66ee6d2e98e857d796dd14391d5/Quantum_labs/отчет_Болс.zip)
- В общей осциллограмме 501 отсчёт с шагом 10 нс. По ней определена задержка 3,40 мкс. [C2300000.txt](../raw%20data/C2300000.txt)
- Для отношения площадей использованы две подробные записи с шагом 0,2 нс. По порядку записи они отнесены к короткому плечу и плечу с катушкой соответственно. [C2300001.txt](../raw%20data/C2300001.txt) · [C2300002.txt](../raw%20data/C2300002.txt)

На с. 31 старого отчёта указаны задержка 4,66 мкс и шаг 20 нс. Новая оценка длины и ослабления относится к трём приложенным файлам. Из практической части исключены расчёт дисперсии по ширине на полувысоте, анализ спектра электрического сигнала и результаты отдельной серии по нагрузке. Теоретические разделы и рисунки сохранены с уточнениями в описании уширения и поляризационной дисперсии.

## Воспроизведение расчёта и сборка

Для пересчёта нужны Python 3.10 или новее, NumPy и Matplotlib. Скрипт читает исходные файлы из `../raw data/` и обновляет численные результаты и два графика. [analysis.py](analysis.py) · [results.tex](results.tex)

Сборка использует XeLaTeX для кириллицы Unicode, так как в рабочей установке pdfLaTeX отсутствовала кодировка T2A. Нужны TeX Live с XeLaTeX и пакетами LaTeX, `latexmk`, шрифты Liberation Serif и DejaVu. Из этого каталога выполните

    python analysis.py
    latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build -jobname=report main.tex

Готовый файл сборки будет в `build/report.pdf`. Числа и рисунки в репозитории позволяют собрать PDF без повторного запуска Python. Длину и ослабление дополнительно сверили независимым поиском пиков и численным интегрированием линейно интерполированных отсчётов.
