## Воспроизведение расчёта и сборка

Для пересчёта нужны Python 3.10 или новее, NumPy и Matplotlib. Скрипт читает исходные файлы из `../raw data/` и обновляет численные результаты и два графика. [analysis.py](analysis.py) · [results.tex](results.tex)

Фон каждой подробной записи вычисляется по отсчётам до −0,60 нс включительно на её временной шкале. Точка совмещения находится линейной интерполяцией по полувысоте переднего фронта. Площади вычисляются по правилу трапеций от −1,5 до 8,0 нс относительно точки совмещения с интерполяцией на краях окна.

Для оценки погрешности длины положение каждого пика ограничивают ближайшими отсчётами по обе стороны от его максимального отсчёта. При проверке затухания правую границу окна меняют на 5 или 6 нс, среднее фона заменяют медианой или сдвигают границу фонового участка до −1,0 нс. Для каждого варианта перебирают сдвиги каждого фона на его выборочное СКО в обе стороны и пересчитывают площадь также по чётным и нечётным отсчётам. При прореживании сохраняют крайние точки записи для интерполяции границ окна. Удельное затухание пересчитывают по крайним значениям ослабления и сеточной погрешности длины.

Для сборки нужны pdfLaTeX с русской локализацией и шрифтами T2A, пакеты LaTeX из исходного архива и `latexmk`. В TeX Live на Debian эти зависимости обеспечивают `texlive-lang-cyrillic`, `cm-super` и `texlive-latex-extra`. Файл сборки определяет разделитель подписей таблиц, указанный в архивной преамбуле. [build.tex](build.tex)

Из этого каталога выполните

    python analysis.py
    latexmk -pdf -bibtex- -interaction=nonstopmode -halt-on-error -outdir=build -jobname=report build.tex

Готовый файл сборки будет в `build/report.pdf`. Числа и рисунки в репозитории позволяют собрать PDF без повторного запуска Python.
