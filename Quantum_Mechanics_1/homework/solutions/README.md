## Сборка из LaTeX

Документы собраны XeLaTeX с кириллицей Unicode и шрифтом DejaVu Serif. Нужны XeLaTeX, `latexmk`, этот шрифт и пакеты `amsmath`, `amssymb`, `fontspec`, `geometry`, `hyperref` и `polyglossia`. Общая преамбула лежит рядом с исходниками. [common.tex](common.tex)

Из каталога с исходниками выполните

    latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir=build hw-*.tex

Для одного листка замените `hw-*.tex` на нужный файл, например `hw-09.tex`.
